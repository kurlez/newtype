# Changelog

- 2026-11-12: A Groq rate limit (HTTP 429, 503, or `rate_limit_exceeded`) retries that speech or rewrite step once on OpenAI when an OpenAI key is saved. The next dictation tries Groq again, unless Groq sent Retry-After. History records the provider that answered. The setting is on by default.
- 2026-11-12: A new install uses Groq whisper-large-v3-turbo and openai/gpt-oss-20b (reasoning effort low). Groq + GPT-4o mini is a separate preset and keeps the Groq and OpenAI keys apart. OpenAI's suggested models are gpt-transcribe and gpt-4o-mini. A saved provider and its model ids stay as they are. Preset prices are about $1.8, $2.5, and $8 per month at 200 dictations a day.
- 2026-11-12: Hotkey capture suspends matching and records the whole chord, including Right Alt + Slash. The main window on Windows can use Mica, Acrylic, or a light Windows 10 transparency, and the settings page hides the vertical scrollbar.
- 2026-11-12: Dictation restores the window that had focus before paste. If it cannot, the text stays on the clipboard and in History. History is the first tab, a tray item, and a last-result card. The main window minimizes instead of hiding. Windows hotkey capture hears modifier keys, including Right Alt when Windows also injects Left Ctrl. Dictionary import merges JSON, one-term lines, and `term,replacement1|replacement2`, and history shows applied and possible dictionary terms.
- 2026-11-12: macOS CI can sign with a stable self-signed identity (`APPLE_CERTIFICATE`, `APPLE_CERTIFICATE_PASSWORD`, `APPLE_SIGNING_IDENTITY`). Missing secrets stay on ad-hoc. Downloaded `llama-server` binaries are signed as one set.
- 2026-11-12: SenseVoice-Small int8 is an optional local speech model (sherpa-onnx, not the default). The About page attributes FunASR only after it is installed.
- 2026-11-12: Skipping the local download asks for confirmation, and the warning stays until both the speech model and the rewrite model are installed. The cloud section says that a recording is sent to the configured provider.
- 2026-11-12: Volcengine speech uses the official openspeech socket (`bigmodel`, resource `volc.seedasr.sauc.duration`). A missing microphone or Accessibility permission shows a prompt that opens the matching system settings pane.
- 2026-11-12: Translate and command hotkeys record. Translate inserts text in the target language (English by default). Command rewrites a selection or inserts generated text. The dictionary imports and exports JSON, and history can be searched, inserted again, cleared, and kept for a chosen period.
- 2026-11-12: Auto routing falls back to local models when the cloud provider is unreachable, retries the same recording if a cloud call fails, and strict offline blocks outbound pipeline traffic.
- 2026-11-12: Local dictation can use Qwen3-ASR and a Qwen3 rewrite model. Weights download on demand and are checksummed before they count as installed.
- 2026-11-12: API keys are stored in the OS credential store, and dictation errors open the indicator.
- 2026-11-11: Test build to verify in-app auto-update (dev.5).
