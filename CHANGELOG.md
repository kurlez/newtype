# Changelog

## Unreleased

- Right Option+/ and Right Alt+/ no longer type an extra character into the focused app. macOS uses an active event tap when Accessibility is allowed and swallows that slash, including its key-up. Without Accessibility the tap only listens and the app says why. Windows swallows the slash and the following Alt release, and the extra Ctrl that arrives with Right Alt does not change the chord.
- After a paste, newtype can watch the same field for up to 45 seconds. A spelling change is suggested only after two identical reads, and only once per dictation. A one-character CJK edit is stored with its neighbour, except a function character, which is ignored. A same-pinyin name stays a suggestion until it is accepted. A capitalised common word such as Their is not learned. Auto-add waits until the same pair appears in two different dictations. Deleting an auto-added term keeps it from coming back. The dictionary can filter Auto-added and Manual entries. The log records only how many were added. Password fields are skipped.
- Dictation remembers the focused field and puts the text back there. Clipboard paste is tried first. If that app cannot be focused again, the text stays on the clipboard and the overlay says to paste it. A successful paste restores the previous clipboard unless the user copied something else in the meantime. Return to the original input field is on by default. Paste last transcript from the hotkey goes into the field in front. The tray item uses the last dictation field.
- The hotkey path no longer does focus or microphone work before the key is queued. Windows keeps the low-level hook callback to a channel send. macOS re-enables a disabled event tap without extra work in the callback. The microphone opens when dictation starts and closes after 30 seconds of idle. A press shows Starting immediately, and Listening plus the start sound wait until samples arrive. In hold-to-talk, a hold shorter than 0.3s is cancelled. Toggle still starts and stops on a tap. Escape still cancels. A modifier is released only when the OS reports it up. A non-modifier that has not repeated for 10 seconds is released. A missing hook, a missing permission, or a silent microphone is shown on the overlay.
- On macOS 26 the app no longer crashes at launch while opening the floating indicator. The indicator window is configured when it is created, and its style mask is not changed after the web view is attached.
- On macOS 26 the floating indicator is shown without becoming the key window, and its window class is left unchanged. Swapping that class aborted AppKit while the window was ordered in.
- On macOS 26 the hotkey listener no longer looks up the key name on the listener thread. That lookup aborted inside the text input system on the first key. The listener reads the hardware keycode instead.
- On macOS, launch asks for the microphone when it has not been decided, and for Input Monitoring when the hotkey tap is not allowed. The hotkey listener keeps trying every two seconds until the tap exists, and turns the tap back on if macOS disables it. Permissions lists Microphone, Accessibility, and Input Monitoring separately. After an update, an old ad-hoc newtype entry may need to be removed and added again.
- A failed model download deletes its partial file and any half-unpacked directory. The next attempt keeps a partial file only when its size still fits and the finished file can be checksummed. Archives are unpacked in a temporary directory and moved into place only after they succeed. The macOS llama.cpp package is unpacked including its relative library links, which is what stopped Qwen3-ASR 1.7B at the extracting stage. Each model has a Clear and re-download action, and the error names the stage that failed.

## 0.2.1

Public release notes. A `v0.2.1` tag publishes that version on the stable channel. Later builds from `main` are `0.2.2-dev.N`, which the updater treats as newer than `0.2.1`.

- The project is dual-licensed under MIT or Apache-2.0. Third-party licenses, including the MPL-2.0 crates and the downloaded models, are summarized in `THIRD_PARTY_NOTICES.md`.
- The README is an end-user guide in English and Simplified Chinese. Download, install, API keys, local models, default hotkeys, and privacy are documented there. Version scheme, signing, and the publish flow are in `docs/RELEASING.md`.
- A new install follows the stable update channel. A channel already saved as dev or stable is left as it is.
- newtype is described as an AI voice input method and is not affiliated with or endorsed by Typeless.
- The log redacts Groq `gsk_` keys, Volcengine `AKLT` keys, Alibaba `LTAI` keys, and other long token-like strings.

## 0.2.0

First stable release. A `v0.2.0` tag publishes that version on the stable channel and, when the dev feed is older, on the dev channel too. Later builds from `main` are `0.2.1-dev.N`, which the updater treats as newer than `0.2.0`.

- The Windows status strip sits in the taskbar, flush with its height, and stays above the Windows 11 taskbar. A maximized window no longer hides it. Floating and hidden remain available.
- The keyboard hook runs on its own message pump and is reinstalled if Windows drops it. Dictate can be chosen from a list. Enter and Escape reach other apps unless they finish a saved chord or a recording is in progress. Saving one setting no longer clears hotkeys.
- A new install uses Groq for speech (`whisper-large-v3-turbo`) and rewrite (`openai/gpt-oss-20b`). A Groq rate limit retries that step once on OpenAI before the local model. Each provider has a Test connection button. Saved API keys drop surrounding whitespace.
- Cloud speech and rewrite failures name the provider, endpoint, model, HTTP status, and a short redacted reason. The fallback status shows that reason.
- The speech prompt stays inside each provider's character budget. Groq is 896 characters and OpenAI is 800, newest terms first, and a term is never cut in half. A prompt-length rejection is retried once with an empty prompt. Rewrite still sees the full dictionary.
- Settings can compare Groq, Volcengine, and DashScope on one recording: raw text, polished text, both latencies, and a redacted error. Volcengine and DashScope receive the dictionary as native hotwords. The result can be saved on this computer.
- Translate and command record. History can be searched, copied, inserted again, and kept for a chosen period. Local Qwen speech and rewrite models download on demand. API keys stay in the macOS Keychain or Windows Credential Manager.
